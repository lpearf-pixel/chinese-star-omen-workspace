## Accepted package boundary

1. B9-PR-E consumes the frozen `AstronomyEvent/v1`, `RuleAssessment/v1`, `VideoPackage/v1`, `EvidenceBundle/v1`, `EditorialPackage/v1` and `StellariumScript/v1` without changing their semantics.
2. A package manifest inventories every structured member by canonical relative path, exact byte size and SHA-256.
3. Structured members are limited to 10 MiB total and 256 members. `manifest.json` is reserved and generated by the package writer.
4. Member paths must be canonical POSIX-relative paths. Absolute paths, traversal, duplicate separators, dot segments, backslashes, control characters and manifest-name collision fail closed.
5. Package publication uses a staging directory on the output filesystem, validates all staged bytes, writes and fsyncs members, then performs an atomic no-replace directory rename.
6. Linux uses `renameat2(RENAME_NOREPLACE)` and macOS uses `renamex_np(RENAME_EXCL)`. Platforms without a trustworthy no-replace primitive fail explicitly; they do not fall back to overwrite-capable rename semantics.
7. Existing output, including a target created during publication, is never replaced. Failure removes only the incomplete staging directory.

## Accepted SRT boundary

- SRT is generated deterministically from the reviewed one-shot-per-claim timeline.
- Cue indexes are contiguous, start at zero time, are continuous and non-overlapping, and end exactly at the editorial duration of 80,000 ms.
- Each cue references the corresponding claim ID and uses a single safe text line; newline, carriage return and NUL fail closed.
- SRT metadata, canonical content and SHA-256 validate each other.
- Repeated generation from identical input is byte-identical.

## Accepted review boundary

Exactly four dimensions are required, in canonical order:

```text
astronomy
classical_evidence
editorial
render
```

Each dimension has one independent reviewer role, decision, explicit UTC timestamp, reason and dimension-specific artifact hash.

Artifact binding is:

```text
astronomy         = SHA-256(canonical AstronomyEvent/v1)
classical_evidence= SHA-256(canonical {RuleAssessment/v1, EvidenceBundle/v1})
editorial         = SHA-256(canonical EditorialPackage/v1)
render            = StellariumScript/v1 content SHA-256
```

Using the `.ssc` hash for all four dimensions is rejected. The gate also validates event, assessment, rule-set, editorial package, script and review-package identities before considering decisions.

`previewable` requires all four decisions to be `approved`. A rejected or needs-revision dimension produces a blocked gate with explicit reasons.

`classical_publishable=true` additionally requires:

- `previewable` review status;
- `EditorialPackage.classical_status=included_citable`;
- exactly one narration-allowed evidence lineage.

The July 21 blocked-classical package can be previewable while remaining `classical_publishable=false`.

## Accepted preview boundary

1. B9 constructs, but does not execute in ordinary CI, a fixed `ffmpeg` argv for a silent 1080x1920 black-background preview with SRT and `libx264`.
2. The command is an argv list with `shell=false`; shell metacharacters and arbitrary filters are not accepted.
3. Subtitle and output paths are confined top-level relative files: `subtitles.srt` and `preview.mp4`.
4. Duration is exactly 80,000 ms and timeout is bounded to at most 120 seconds.
5. Required capabilities are exactly the declared `lavfi-color`, `subtitles` and `libx264` features.
6. `preview.mp4` is optional local output and is not a structured package member. `final.mp4` is outside B9.

## Accepted local capability evidence

`LocalCapabilityEvidence/v1` is a path-free metadata interface for a real local or self-hosted renderer run. It records:

- explicit UTC capture time;
- platform and architecture;
- exact Stellarium and FFmpeg versions;
- package `.ssc` SHA-256;
- canonical preview-command SHA-256;
- whether preview execution was observed;
- visual-review status;
- at most 30 confined screenshot paths with size and SHA-256.

An approved visual review requires an observed preview and at least one screenshot. This interface does not claim that ordinary hosted CI launched Stellarium or FFmpeg.

## Hermetic vertical package

The deterministic package member set is:

```text
astronomy-event.json
rule-assessment.json
evidence-bundle.json
video-package.json
editorial-package.json
scene.ssc
subtitles.srt
preview-command.json
review-bundle.json
review-gate.json
```

`local-capability-evidence.json` is included only when verified local evidence is supplied. `preview.mp4`, screenshots and other media remain external optional artifacts whose hashes are recorded by capability evidence.

Two hermetic paths are covered:

1. July 21 public candidate: no classical quote, reviewable/previewable, `classical_publishable=false`.
2. Evidence-rich regression: exact approved quotation present, `classical_publishable=true`.

Neither path performs network access, GUI execution, FFmpeg execution, ingest, Qdrant mutation or publication.
