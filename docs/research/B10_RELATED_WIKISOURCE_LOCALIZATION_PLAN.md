# B10 相关引书 Wikisource 本地化计划

状态：PLANNED / 本轮只登记，不执行下载
提出日期：2026-08-01

## 目标

把 B10 核心 14 条审计中涉及、且 Wikisource 有可定位原文的相关古书，按《唐開元占經》同等级别保存到 GitHub：固定永久 revision、保留原字与卷页结构、记录 accession manifest 与 SHA-256、保存来源链接和访问日期、区分载体/引书/平行文，并附校勘及使用限制。

本计划不把《唐開元占經》中的书名自动视为现存完整书。已佚或仅存辑文的材料，只登记载体内引句和传承身份；没有独立原文时不得伪造“本地化全书”。

## 处理优先级

### P0：直接影响本轮校读或终态裁决

| 书/文献族 | 关联案例 | 处理原因 |
|---|---|---|
| 《乙巳占》 | C13、C47 | `失火／失地`、`謀／誅`、`時／无時` 等关键平行异文 |
| 《史记·天官书》 | C03 | “月蝕岁星”术语与岁星占候平行 |
| 《汉书·天文志》 | C41 | “干太微，入紫宫”校读平行，必须与载体原字分层 |
| 《宋书·天文志》 | C09、C14 | 历史按语与“二月／六月”等日期异文 |
| 《晋书·天文志》 | C03、C14、C47 | 月掩岁星、荧惑守心及彗孛史例 |
| 袁宏《后汉纪》 | C14 | 历史按语续文及饥荒事件平行 |
| 《后汉书》 | C45 | 客星/帝座相关历史按语 |

### P1：有 Wikisource 原文、用于跨卷或历史来源核对

- 《幽明录》现存辑文页面（如可固定可靠版本）：用于 C45 志怪按语身份。
- 可独立定位的《春秋纬》辑文、纬书辑文：只保存实际可定位页面，不把后人辑本和《占经》引句混为一版。
- 与 C09、C11、C31、C33、C43、C44 中史书按语直接对应的传世卷页，经 P0 完成后按案例补列。

### P2：已佚或身份未决的书内引文

《荆州占》《河图帝览嬉》《黄帝占》《黄帝兵法》《玄冥占》《百二十占》《太公阴祕》《高宗日傍气图》《乾象通鉴》《洛书摘亡辟》《钩命决》《文曜钩》《孝经内记》《巫咸》《甘氏》《石氏》《韩杨》等，先做“引句登记”，再判断 Wikisource 是否存在独立可用文本或可靠辑本。

- 有独立页面：转入 P1，固定具体 edition/revision。
- 只有《占经》内引句：保留 carrier-excerpt 身份，不生成独立书文件。
- 只有现代整理或不明转载：不进入原文证据层，另列线索。
- 人名如郗萌、陈卓不得自动改造成书名。

## 分阶段执行

| 阶段 | 工作 | 验收门禁 |
|---|---|---|
| L0 书目消歧 | 保存载体打印名、规范名候选、人物/书名/史书章节类型及关联 case | 每个名字有身份说明；洛/雒、郗/郄等不静默归并 |
| L1 Wikisource 盘点 | 为每部书定位目录、卷页、固定 oldid 和许可信息 | URL 可重放；不使用浮动 current page 作为唯一凭据 |
| L2 原文本地化 | 保存固定 revision 的原始 wikitext/文本、卷页边界、访问日期及 SHA-256 | 下载内容与 manifest 哈希一致；原字和标题结构不被现代标点覆盖 |
| L3 载体交叉核对 | 选择 Kanripo、官方影像或另一可靠古籍源作版本身份核对 | 同源转录不冒充独立异本；差异逐字登记 |
| L4 案例映射 | 建立相关书原子句与 C02–C47 规则/按语的链接 | 映射有方向与 scope；平行、异文、来源、duplicate 分开 |
| L5 QA 与发布 | JSON/manifest 校验、哈希复算、链接重放、人工抽样、GitHub Draft PR | 机器门禁全过；高风险断句仍标未决；不自动 ingest KB |

## 与《唐開元占經》相同的最低保存项

每个实际本地化对象至少包含：

- 书名原写与规范名候选；
- Wikisource title、oldid、永久 URL、访问日期；
- 原始文本与卷/页/章节定位；
- 文件 SHA-256 与 accession manifest；
- 版本系统、转录来源和是否独立见证；
- 与 B10 case/atomic rule 的作用域链接；
- 原文、建议断句、白话释读和校勘异文分层；
- citation whole/atomic 限制；
- 已佚、辑本、人物归属和不确定身份说明。

## 暂不执行的事项

- 不在本轮批量下载 P0–P2 全书。
- 不冻结多文本数据库 schema。
- 不把本地化文件写入官方 KB/Qdrant。
- 不以 CText 或二次转载代替固定原始 revision。
- 不把 Wikisource 与 Kanripo 同源一致计作两个独立异本。
