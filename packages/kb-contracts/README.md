# KB Contracts

Shared upstream/downstream contract package for the monorepo.

## Python helpers

Use by adding the package source to `PYTHONPATH`:

```bash
export PYTHONPATH="$PWD/packages/kb-contracts/python:$PYTHONPATH"
```

Exports:

- `normalize_term(term)`
- `stable_candidate_id(kb_book_id, term, source_locator, match_offset)`
- `sha256_text(text)`
- `load_candidate_manifest(path)` / `save_candidate_manifest(path, manifest)`
- `merge_candidate_item(manifest, item)`
- `ReviewStatus` and `SyncStatus` enums

## Schemas

- `schemas/candidate_card.schema.json`: YAML frontmatter fields for `candidate-card/v1` markdown extract cards.
- `schemas/candidate_manifest.schema.json`: `candidate-manifest/v1` generated by downstream and consumed by upstream.
- `schemas/corpus_manifest.schema.json`: `corpus-manifest/v1` published by upstream after ingest.
