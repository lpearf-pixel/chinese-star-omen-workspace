# B10 Core14 research evidence package

This directory is an AI research pre-review package for the fourteen frozen B10 pilot cases. It is not a human Reviewer A/B return, a production schema, or an official knowledge-base ingest.

## Contents

- `B10_CORE14_SOURCE_AUDIT_REPORT.md`: integrated Chinese report and fourteen-case decision matrix.
- `B10_RELATED_WIKISOURCE_LOCALIZATION_PLAN.md`: deferred plan to localize related Wikisource books with the same provenance treatment as 《唐開元占經》.
- `wikisource-revision-register.json`: thirteen permanent Wikisource revisions for the carrier volumes.
- `kanripo-core14-contexts.txt`: page windows around every frozen row at the pinned Kanripo commit.
- `audit-early.json`, `audit-middle.json`, `audit-late.json`: structured working evidence; not a frozen production schema.
- Markdown audits and cross-review records under `docs/research/core14-case-audits/` in the repository.
- `accession-manifest.json`: file hashes and lineage.
