# 使用说明

> 这份说明面向未来的自己：这套《唐開元占經》库应该怎么用，先看什么，遇到问题去哪找。

## 一、这套库包含什么

### 1. 原始语料
- `唐開元占經-全文合併版.md`
- `分卷/KR3g0018_000.md` 到 `分卷/KR3g0018_120.md`

用途：
- 全文检索
- 核对原文
- 分卷精确定位

### 2. 知识组织文件
- `术语卡片/`
- `主题索引/`
- `逐宿卡/`
- `星官卡/`
- `章节摘要卡/`
- `知识抽取卡/`

用途：
- 帮助 Agent 更稳地回答概念、结构、专题类问题
- 给自己做长期积累，不必每次都回到原文重新读

### 3. 验证与测试
- `问答样例库/`
- `agent/eval/`

用途：
- 测路由是否正确
- 测回答是否贴近原文
- 测知识抽取是否稳定

### 4. Agent 配置
- `agent/prompts/`
- `agent/extract/`
- `agent/eval/`
- `agent/schema.yaml`

用途：
- 问答
- 抽取
- 专题总结
- 自动评测

## 二、推荐阅读路径

### 路径 A：想先理解整本书
1. 看 [[分卷/KR3g0018_000]]
2. 看 [[分卷/KR3g0018_001]]
3. 再看 [[主题索引/天體與曆法]]
4. 然后按兴趣转入 `日占 / 月占 / 五星占 / 星圖 / 雜占`

### 路径 B：想直接拿来做问答
1. 打开 [[00-总索引]]
2. 看 [[02-Agent入口]]
3. 用 `问答样例库/` 先跑几轮测试
4. 如果回答不稳，再补 `术语卡片/` 和 `主题索引/`

### 路径 C：想做知识抽取
1. 先读 `agent/prompts/extraction-prompt`
2. 再看 `知识抽取卡/`
3. 按术语或主题继续补卡

## 三、检索策略建议

### 1. 查术语
先搜：
- `术语卡片/`
- `知识抽取卡/`
- 再回到 `分卷/`

### 2. 查卷目结构
先看：
- [[分卷/KR3g0018_000]]
- `导航/主题总览`
- `导航/章节摘要總覽`

### 3. 查专题
先看：
- `主题索引/`
- `逐宿卡/`
- `星官卡/`

### 4. 查具体原句
优先：
- `分卷/`
- `唐開元占經-全文合併版.md`

## 四、维护原则

### 原则 1：原文层与解释层分开
- 原文尽量留在 `全文合併版` 和 `分卷/`
- 解释尽量放进 `术语卡片/`、`主题索引/`、`知识抽取卡/`

### 原则 2：先链接，后扩写
如果来不及写长文，先加：
- 原文出处
- 相关术语
- 相关主题
- 回链到总索引

### 原则 3：避免重复解释
相同概念尽量只在一个术语卡片里做主解释，其他文件用链接引用。

## 五、后续补充优先级
1. 术语卡片再补齐高频概念
2. 主题索引补更多“卷号 + 摘要 + 术语”
3. 逐宿卡补原文摘录
4. 星官卡补星官之间的关系
5. 问答样例库继续扩写

## 六、目前最值得测试的问题
- 什么是渾天？
- 黄道与赤道是什么关系？
- 卷一主要讲什么？
- 星圖在哪几卷？
- 客星、彗星、妖星有何区别？
- 北斗、紫微、太微、天市分别是什么？

## 七、日常使用建议
- 把 [[00-总索引]] 设成这个文件夹的默认起点。
- 每次补新卡片时，记得回链到 `00-总索引` 或对应 `导航/` 文件。
- 每补完一个主题，最好同步补一个问答样例。
