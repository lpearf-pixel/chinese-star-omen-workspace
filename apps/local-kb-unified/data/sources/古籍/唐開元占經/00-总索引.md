## 八、推荐使用顺序
1. 先看 [[01-使用说明]]。
2. 想看原文，优先用 [[唐開元占經-全文合併版]] 和 `分卷/`。
3. 想理解概念，优先看 `术语卡片/`。
4. 想按专题整理，优先看 `主题索引/`。
5. 想测试问答效果，优先看 `问答样例库/` 与 [[02-Agent入口]]。

## 九、维护约定
- 原始文本尽量不改，只做链接和少量 frontmatter 补充。
- 解释性内容优先放在术语卡片、主题索引、知识抽取卡里。
- Agent 提示词集中维护在 `agent/prompts/`。
