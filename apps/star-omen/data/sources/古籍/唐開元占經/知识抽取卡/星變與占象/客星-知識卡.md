# 客星

## 摘要
客星是指非常見、非常住之星，常被視為重大變異信號。

## 原文摘錄
> 客星占一。

## 白話解釋
在占經體系裡，客星常因其突然出現、停留與犯入某區，被用來判斷政局、兵事與災異。

## Agent 回答口徑
- 先講“非常住之星”的特性。
- 再講其占驗依賴所犯星區。
- 不要把所有新星現象簡單等同。
